# VoIP related codes
 
<br> 

This repository contains various resources that are helpful when operating SIP softswitches such as FreeSWITCH.

* How to Use Various FreeSWITCH Modules and Scenario Writing Tips
* How to convert audio and video files using tools such as ffmpeg and sox
* C example code that can convert between g.711 codec and 16k PCM files
* A tool for analyzing SIP messages in pcap files
